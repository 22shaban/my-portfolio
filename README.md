# Shaban Shaikh — Portfolio

Personal portfolio for a cloud & infrastructure engineer, built on the editorial
template: oversized serif type, a fog/ink theme pair, a binary preloader, a fluid
WebGL backdrop and a work index with shader-driven hover reveals.

Content is editable from a browser at `/admin` (Sveltia CMS). The work entries
currently in `content/projects/` are placeholder projects.

**Placeholder assets.** Fonts are OFL stand-ins; project plates are drawn
procedurally in `lib/workTextures.ts`. No proprietary fonts, images, videos or
personal text from any reference site are included.

---

## Stack

| Layer | Choice |
| --- | --- |
| Framework | Next.js 15 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 (`@theme` tokens in `app/globals.css`) |
| Motion | GSAP 3 + ScrollTrigger + SplitText + ScrambleText + CustomEase |
| Smooth scroll | Lenis |
| 3D / shaders | Three.js (raw, no R3F) |
| Fonts | Editorial display + Playground accent + Sometype Mono (OFL stand-ins) |

## Design tokens

All tokens live at the top of `app/globals.css`.

### Colour

| Token | Fog (default) | Ink |
| --- | --- | --- |
| `--c-base` | `#e8e5df` | `#050505` |
| `--c-fg` | `#14130f` | `#f2efe8` |
| `--c-muted` | `#6d6a62` | `#8a867d` |
| `--c-line` | `rgba(20,19,15,.18)` | `rgba(242,239,232,.22)` |
| `--c-panel` | `rgba(255,255,255,.38)` | `rgba(255,255,255,.04)` |

The fog gradient is painted by the WebGL fog shader; the CSS `--c-bg` radial
gradient is the fallback for reduced-motion and no-WebGL environments.

### Type

The scale is `svw`-based and has three breakpoints: phone, `tab` (≥768px and
aspect-ratio ≥ 3/5) and `desktop` (≥1200px).

| Utility | Phone | Tab | Desktop |
| --- | --- | --- | --- |
| `text-hero` | 14.92svw | 12svw | 7.52svw |
| `text-xl` | 20.94svw | 8.2svw | 4.86svw |
| `text-l` | 7.46svw | 3.9svw | 2.31svw |
| `text-m` | 6.23svw | max(15px, 1.95svw) | max(20px, 1.56svw) |
| `text-ms` | 4.47svw | max(15px, 1.75svw) | max(15px, 1.04svw) |
| `text-mxs` | 3.99svw | max(14px, 1.56svw) | max(15px, .92svw) |
| `text-xxs` | 2.98svw | max(12px, 1.17svw) | max(12px, .69svw) |

All three breakpoint sets are copied 1:1 from the reference. Display type is
uppercase with `0.03em` tracking and `0.85` line-height; mono is Sometype Mono.

The display faces try `local("PP Editorial Old")` / `local("PP Playground")`
first. If you own those fonts, install them or drop the `.woff2` files into
`public/fonts/` and put their URLs first in the `@font-face` `src` lists — the
type then matches the reference exactly. Bundled fallbacks are Instrument
Serif (display) and Lobster (the single accent glyph), both OFL.

### Motion timings (from the reference bundle)

- Loader counter steps: `10/.75s, 35/.6s, 70/1s, 100/.9s` on the CustomEase
  `M0,0 C0.104,0.204 0.711,0.986 1,1`.
- Masked text reveal (`mainTextIn`): `inset(-50% 0% 150% 0%)` →
  `inset(-50% 0% 0% 0%)`, `yPercent 110 → 0`, `1.5s expo.out`, `0.1s` line stagger.
- Work rows: `clipPath inset(0 0 100% 0)` + `yPercent 100`, `1s expo.out`.
- Work title roll: `0.8s`, `0.06` per-character stagger, scrubbed with `expo.out`.
- Theme crossfade: `1s power2.inOut` (CSS + shader uniform).
- Lenis: `smoothWheel` only (library defaults for everything else).

### Grid

`--grid-margin: 24px` on every breakpoint. `--grid-gutter: 10px` → `24px` at `tab`.
The work index uses a 120-column logic (29.17% / 20.83% columns).

## Editing content (admin panel)

All copy and projects live in `content/` as plain JSON. The panel at
**`/admin`** (Sveltia CMS) edits those files through GitHub — no code, no
database, no server.

| What you edit | Where it is stored |
| --- | --- |
| Name, hero headline, about copy, contact, socials, ticker, nav, confidential card | `content/site.json` |
| One project per file: title, year, order, tags, awards, plate hue, blurb | `content/projects/*.json` |
| Uploaded images (optional, not used by the plates yet) | `public/uploads/` |

The site is a static build, so publishing works like this:

```
/admin → Publish → commit to GitHub → host rebuilds → live in ~1 minute
```

### One-time setup (about 5 minutes)

**1. Put the project on GitHub**

```bash
git init -b main
git add .
git commit -m "Portfolio template"
# create an empty repository on github.com, then:
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

**2. Point the CMS at that repo** — in `public/admin/config.yml`:

```yaml
backend:
  name: github
  repo: USERNAME/REPO
  branch: main
```

**3. Create an access token** — GitHub → *Settings* → *Developer settings* →
*Personal access tokens* → *Fine-grained tokens* → *Generate new token*.
Repository access: only this repo. Permissions: **Contents — Read and write**.
(A classic token with the `repo` scope also works.)

**4. Sign in** — open `https://your-site.com/admin` (or
`http://localhost:3000/admin`), click **Sign In Using Access Token** and paste
the token. It stays in that browser only; nothing is stored in the repo.

### Day to day

- **Site** → Site settings: edits `content/site.json`.
- **Work** → a project: edits `content/projects/<slug>.json`.
- `order` decides the position in the work index (lower = first).
- **Publish** commits. Deleting a project deletes its JSON file.
- Images dropped into an Image field land in `public/uploads/`.

### Notes

- Adding or removing a project needs no code change: `scripts/build-content.mjs`
  regenerates `content/projects.generated.ts` from the folder before every
  `npm run dev` and `npm run build`. Run it by hand with `npm run content`.
- Prefer editing locally? On the login screen choose **Work with Local
  Repository** and pick the project folder — the browser writes the JSON files
  directly, no GitHub token involved.
- Want a "Sign in with GitHub" button instead of a token? Deploy
  [sveltia-cms-auth](https://github.com/sveltia/sveltia-cms-auth) to Cloudflare
  Workers, then uncomment `base_url` in `config.yml`. Optional.
- The panel is excluded from search engines (`noindex` header + meta tag).

## Deploying

**Vercel (recommended for this project)** — import the repo at
[vercel.com/new](https://vercel.com/new), keep the detected Next.js preset, deploy.
`npm run build` regenerates the project list automatically.

**Cloudflare** — Cloudflare Pages' built-in Next.js support is deprecated; the
supported path is Workers + the OpenNext adapter
(`@opennextjs/cloudflare`). It works, costs less at scale, and needs extra
config. Not required for a portfolio.

Either host rebuilds on every commit the CMS makes, so the `/admin` workflow is
identical on both.

### Metadata, canonical URL and social previews

Titles, description, keywords, `Person` JSON-LD (`app/layout.tsx`), `sitemap.xml`
(`app/sitemap.ts`) and `robots.txt` (`app/robots.ts`) all read from
`lib/site-meta.ts`.

The canonical URL lives there too. It defaults to `https://shabanshaikh.me`, and
`NEXT_PUBLIC_SITE_URL` overrides it at build time if the domain ever changes:

```
NEXT_PUBLIC_SITE_URL = https://shabanshaikh.me
```

`robots.txt` keeps `/admin` out of search results, and the admin route also sends
`X-Robots-Tag: noindex, nofollow` (`next.config.ts`).

Social preview image: `public/og.png` (1200×630). Regenerate it by editing
`ref/og.html` and running `node ref/og-shot.mjs` — those two files are local
research artifacts and are not committed.

## Customising

1. **Copy & projects** — use `/admin`, or edit `content/site.json` and
   `content/projects/*.json` by hand.
2. **Colours** — edit `:root` and `[data-theme="ink"]` in `app/globals.css`.
3. **Fonts** — swap the `@font-face` blocks and `--font-display` / `--font-mono`.
4. **Work art** — `lib/workTextures.ts` draws each project plate procedurally
   (hover card + dialog plate). Swap `drawWorkTexture` for an image loader if
   you have real stills.
5. **WebGL** — `components/webgl/FogScene.ts`. `OCTAVES` and the pixel-ratio
   clamp control cost; the scene auto-downgrades if frames exceed ~24ms.
6. **Sections** — reorder `<Hero />`, `<About />`, `<Interlude />`, `<Studio />`,
   `<WorkList />` in `app/page.tsx`.

## Motion inventory

- Binary preloader with a four-step custom-eased counter and binary scramble-in,
  using the reference's exact timings and cluster layout.
- Hero: masked line reveal (1.5s expo.out, 0.1s stagger), binary scrambling meta
  strip and pop-in bullets/arrows.
- Scroll reveals via GSAP ScrollTrigger (`components/ui/Reveal.tsx`).
- Work titles: per-character hover slide (duplicate line technique), 0.8s with
  0.06 stagger, scrubbed with expo.out.
- Work hover: a lagging floating card with a procedurally drawn project plate,
  shown above the row and above the page content (no image assets).
- Theme switch: 1s power2.inOut crossfade between the CSS tokens and the
  shader's `uTheme` uniform (no radial wipe).
- Status ticker, marquee, custom cursor with contextual labels.
- `prefers-reduced-motion` disables Lenis, the preloader animation, the WebGL
  fog, the hover card motion and all scroll reveals; the CSS fog gradient and
  static layout remain.

## Accessibility notes

- Semantic headings, skip-friendly landmarks, `aria-label` on icon buttons.
- Work rows expose a real `<button>` overlay, so keyboard focus and screen
  readers work even though the visual row is a table-like layout.
- The project dialog closes on `Escape`, restores focus and stops Lenis.
- Colour contrast is stronger than the usual "white on grey" editorial look:
  fog uses dark ink on light grey. Adjust tokens if you want the ghostlier
  reference look, but check contrast first.
